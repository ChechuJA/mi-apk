Test de menu-local.html

Prueba del menú local

Este test carga menu-local.html en un iframe para verificar que se renderiza correctamente.

Nota importante: El iframe aquí es solo para testing. La diferencia clave del fix es que los juegos dentro de menu-local.html ya NO usan iframes - ahora se cargan directamente con script tags.

Si ves el menú de juegos abajo, el fix funciona correctamente.

Si ves una pantalla negra, hay un problema que necesita más investigación.

Limitación: Los juegos pueden no funcionar completamente en este test porque los scripts de juego intentarán cargar recursos que no están en el mismo contexto.

Instrucciones de prueba:

  1. Verifica que el menú de juegos se muestre correctamente
  2. Haz clic en un juego para ver si se carga
  3. Verifica que los controles móviles aparezcan (si estás en móvil)
  4. Verifica que el botón "Volver" funcione
